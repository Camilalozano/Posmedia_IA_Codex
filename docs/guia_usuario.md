# Guía de usuario

1. Indique el número de proceso.
2. Cargue la minuta PDF si desea extraer datos contractuales y obligaciones IES. La consulta automática del proceso se implementará después.
3. Cargue las evidencias PDF, individualmente o dentro de un ZIP. Límite: 50 PDF, 20 MB por PDF y 100 MB descomprimidos en total. No se admiten ZIP cifrados, ZIP anidados ni otros formatos.
4. Pulse Preparar borrador. Revise el inventario y los mensajes de lectura. Un PDF escaneado requiere OCR externo o revisión manual.
5. Corrija los campos, incluido el número contractual; complete el periodo y demás datos de ejecución. Revise y complete las obligaciones, una por línea.
6. Para cada obligación escriba las actividades realizadas y seleccione los archivos que las respaldan. Consulte el texto extraído por página. La aplicación no determina por sí sola si esas evidencias demuestran cumplimiento.
7. Genere y descargue el Word y la trazabilidad JSON. Revise el documento antes de presentarlo; el supervisor debe diligenciar su sección y aprobar el contenido.

Al cambiar los archivos o el número de proceso se descarta el borrador anterior. Al modificar un dato se invalida la descarga anterior hasta generar de nuevo.
